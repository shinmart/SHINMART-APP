# Контракт интерфейс ↔ сервер

Источник правды — `docs/api/SPEC_APP.md`. Метод и ответ описываются там
первыми.

## Форма

- Вызов: `run('appИмя', { reqId, …параметры })`. Любая запись получает
  `reqId: rid()` — повтор с тем же `reqId` вернёт тот же ответ.
- Ответ: `{ ok: true, … }` или `{ ok: false, error: 'текст причины' }`.
  Клиентская `run` превращает `ok:false` в исключение.
- Даты — строка `ГГГГ-ММ-ДД`, деньги — целые тенге, кол-во — целые.
- Сервер ничего не форматирует для показа, кроме коротких подписей.

## Кто что решает

| | Сервер | Интерфейс |
|--|--------|-----------|
| Права, роль | проверяет, вычищает поля | показывает по `role` |
| Остатки, FIFO, комиссии, балансы | считает | показывает |
| Валидация суммы, счёта, ссылки | проверяет | подсказывает |
| Текст ошибки | отдаёт причину | показывает в баннере/тосте |

## Правила

- Новое поле с себестоимостью/маржой — сразу в `opsScrub_`.
- Запись в таблицу, потом запись в кэш (если нужна), никогда наоборот и
  всегда в `try/catch` (L-008).
- Ответ больше ~90 КБ в кэш идемпотентности не кладётся.
- Изменился ответ — обновить `SPEC_APP.md` и интерфейс в одном коммите.
