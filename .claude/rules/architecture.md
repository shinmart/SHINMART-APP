# Архитектура: Apps Script + листы

Слоёв два: **интерфейс** (`Index.html`) и **сервер** (`.gs`). Данные — листы,
каждая операция одной строкой. Цель — чтобы переезд на базу данных был
«лист → таблица», без переписывания логики.

## Куда класть код

| Что | Куда |
|-----|------|
| Меню таблицы, FIFO, Kaspi, общие хелперы | `Code.gs` (не дублировать) |
| Доступ, обёртки, продажи, приход, итоги, миграция листов | `WebApp.gs` |
| Настройки, роли, счета, переводы, вложения, комиссии | `Ops.gs` |
| Экраны и их JS | `Index.html` (секции `/* ---------- … ---------- */`) |
| Новая тема больше ~400 строк | новый `.gs` рядом, по образцу `Ops.gs` |
| Проверка серверной логики | `tests/*.test.js` |

## Серверные функции

- **Публичная** `appИмя(p)` — то, что зовёт интерфейс. Всегда
  `return appGuard_(p, write, email => …)`: он проверяет доступ
  (`APP_ALLOWED`), защищает от двойного нажатия (`reqId`), берёт блокировку
  записи и вычищает данные по роли (`opsScrub_`).
- **Внутренняя** `имя_()` — суффикс `_`, из интерфейса недоступна.
- Метод, который меняет данные, проверяет роль: `opsNeedOwner_(email)`.
- Любая запись → строка в `APP_ЖУРНАЛ` через `appLog_` и возможность отмены.
- Тяжёлое (пересчёт FIFO) — отдельным методом после быстрой записи
  (L-006).

## Данные

- Деньги — в `ДВИЖЕНИЕ_ДЕНЕГ` одной строкой на движение (`+`/`−`); остаток
  счёта = начальный + сумма неотменённых. Связь с источником — колонка
  «СВЯЗЬ» (`EX<строка>`, `TR<id>`).
- Даты — объекты `Date` в ячейке, формат задавать `setNumberFormat`. Ключ
  дня в обмене с интерфейсом — строка `ГГГГ-ММ-ДД`.
- Шапка дня в журнале продаж: `Date` в колонке A (L-007).
- Новая колонка в существующем листе — в конец, заголовок задаёт код
  (`appEnsureCol_`), старые колонки не двигать.

## Запреты

- `setValues` со строкой, начинающейся на `=` (L-009).
- Пустой `catch`; исключение — запись в кэш (L-008), и там пишется причина.
- Доверять данным интерфейса: сумму, счёт, ссылку на файл проверять на
  сервере (пример: ссылка вложения — только `drive.google.com`).
- Хранить в интерфейсе (`localStorage`) то, что должно быть общим.
- Права «продавец» только скрытием в интерфейсе (L-013).
- Публичный метод без `appGuard_`.
