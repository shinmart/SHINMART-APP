# Дизайн: телефон первым

Карта готовых элементов — [`docs/code/ui/components-map.md`](../../docs/code/ui/components-map.md).
Прежде чем создавать элемент, проверить её.

## Токены

- Цвета, фон, линии — только CSS-переменные из `:root` в `Index.html`
  (`--ink`, `--ink2`, `--bg`, `--card`, `--line`, `--fill`, `--accent`,
  `--accent-d`, `--accent-ink`, `--green`).
- Новый цвет — сначала переменная, потом использование. Сырые `#hex` в
  новых правилах не писать.

## Элементы

- Крупное действие — `.go` (оранжевая кнопка 58 px), вторичное — `.btn`,
  главное вторичное — `.btn.pri`.
- Поля — `.inp`, выбор — `.sel`, список — `.op` (строка операции), `.acc`
  (счёт), `.lnk` (пункт меню «Ещё»), фильтры — `.chips`, `.pills`.
- Итог — `.sum3`, пусто — `.empty`, ошибка — `.banner`, подтверждение —
  `.dlg`, всплывающее — `toast()`.
- Деньги пишутся через `money()` (`12 345 ₸`), числа — `fm()`.

## Вёрстка

- Эталон ширины — 390 px, без горизонтальной прокрутки.
- Тап-зона не меньше 44 px; состояние не передаётся одним цветом.
- Себестоимость и маржа — класс `secret` (скрываются режимом «глаз»);
  элементы только для владельца — класс `owner` (скрыты у продавца, но
  данные продавцу всё равно не отдаются сервером).
- Кнопки не пересоздавать по клику: переключать класс на месте («залипание» кнопок на iPhone).
- Собирая HTML строкой, открывать блок только после ранних `return`.
