# SHINMART-APP

Приложение учёта ШИНМАРТ на Google Sheets + Apps Script (позже перенос на свой сервер).

- `apps-script/` — файлы для проекта Apps Script (`Code.gs`, `WebApp.gs`, `Ops.gs`, `Index.html`).
- Почты в `APP_ALLOWED` заменены заглушками: впишите свои при развёртывании, не коммитьте их в публичный репозиторий.
- Этап 1 «Деньги»: настройки, роли, счета, расходы с чеками, комиссии банков.
