# Карта элементов интерфейса (`apps-script/Index.html`)

Прежде чем писать новый элемент, найди его здесь.

| Элемент | Класс / функция | Для чего |
|---------|-----------------|----------|
| Крупная кнопка действия | `.go` | «Записать», «Перевести» |
| Кнопка | `.btn`, `.btn.pri` | вторичное и главное в диалоге |
| Поле | `.inp`, `.inp.big` | ввод; сумма — крупное |
| Выбор из списка | `.sel` | счёт, категория |
| Метки-фильтры | `.chips`, `.pills` | период, категория |
| Строка операции | `.op` (`.l`, `.r`, `.m`) | расход, комиссия, продажа |
| Строка счёта | `.acc` | счёт и остаток |
| Пункт меню «Ещё» | `.lnk` | переход на страницу |
| Итог | `.sum3` | число с подписью |
| Пусто / ошибка | `.empty` / `.banner` | состояния |
| Подтверждение | `.dlg` + `.box` | вопрос с кнопками |
| Всплывашка | `toast(заголовок, текст, {err})` | результат действия |
| Только владельцу | `.owner` | скрывается при `body.seller` |
| Секрет-цифры | `.secret` | скрываются режимом «глаз» |
| Фото чека | `shrinkPhoto(file)` | сжатие до 1280 px перед загрузкой |
| Деньги / число | `money(n)` / `fm(n)` | форматирование |
| Вызов сервера | `run(имя, p)` | Promise над `google.script.run` |

## Эталонные экраны

| Тип | Эталон |
|-----|--------|
| Форма с записью | `drawExp` |
| Список со счётчиком | `drawAcc` / `renderAcc` |
| Отчёт за период | `drawBank` / `loadBank` |
| Страница настроек | `drawCfg` / `renderCfg` |
| Меню слева на ПК | `renderSide` / `goMenu` (общий переход с шторкой `#menu`) |
