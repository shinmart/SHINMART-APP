# Переезд: Google → свой сервер

Решение владельца (2026-11-26): сначала работаем на Google, потом переезд.

## Целевая схема

Node.js на VPS в Казахстане + PostgreSQL; Google Sheets остаётся зеркалом
для просмотра. Интерфейс `Index.html` переезжает почти без изменений: вместо
`google.script.run` — `fetch` к тем же методам (`SPEC_APP.md`).

## Что уже сделано под переезд

- Каждая операция — строка с источником и отметкой отмены.
- Остатки, балансы и комиссии выводятся из строк, а не хранятся.
- Контракт методов описан в `docs/api/SPEC_APP.md` и не зависит от Google.
- Роли и вычистка данных — на сервере.

## Фазы

1. Описать схему таблиц БД по листам (`ПРОДАЖИ_ЖУРНАЛ`, `ЗАКУПКИ`, `РАСХОДЫ`,
   `СЧЕТА`, `ДВИЖЕНИЕ_ДЕНЕГ`, `НАСТРОЙКИ`, `APP_ЖУРНАЛ`).
2. Однократный перенос данных, сверка итогов и остатков.
3. Серверная логика методов по SPEC, те же ответы.
4. Параллельная работа: запись в БД, зеркало в таблицу.
5. Переключение, Apps Script остаётся запасным.
