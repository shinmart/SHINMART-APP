# Проверка

## Сервер

```bash
node tests/ops.test.js
```

Подставляет модель таблицы вместо `SpreadsheetApp` и прогоняет `WebApp.gs`
+ `Ops.gs`: счета, переводы, расходы с чеком, комиссии, «ждём зачисления»,
роли и вычистку для продавца. Модель **не** воспроизводит локаль, лимиты
Google и скорость — их проверяют в настоящей таблице.

Новый метод → новый сценарий: нормальный путь, отказ продавцу, повтор с тем
же `reqId`, отмена.

## Интерфейс

Скопировать `apps-script/Index.html`, перед основным `<script>` добавить
заглушку `window.google.script.run` (ответы фиксированным JSON) и открыть в
браузере шириной 390 px. Смотреть: загрузка, пусто, ошибка, длинные списки.
