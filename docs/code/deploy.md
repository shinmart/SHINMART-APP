# Выкладка

1. Заменить файлы в проекте Apps Script (имена как в редакторе: `Code`,
   `WebApp`, `Ops`, `Index`). Новый файл — «+» → Скрипт / HTML.
2. В `WebApp.gs` вписать **настоящие** почты в `APP_ALLOWED` (в
   репозитории — заглушки).
3. Открыть таблицу → меню → «Подготовить…» (первый раз и после новых
   листов): `📱 Подготовить приложение`, `💰 Подготовить деньги…`.
   Разрешить доступ к Диску, если спросит.
4. Развернуть → **Управление развертываниями → ✏️ → Новая версия**.
   Ссылка `/exec` остаётся прежней.
5. Проверить с телефона в приватном окне одним аккаунтом.

Доступ: у каждого аккаунта — Редактор таблицы и почта в `APP_ALLOWED`;
`@icloud.com` — не Google-аккаунты. Выдать доступ к таблице может только её
владелец.

Откат: «Управление развертываниями» → выбрать прошлую версию. Старые листы
(`ЗАКУПКИ`, `ПРОДАЖИ`) приложение не меняет.
