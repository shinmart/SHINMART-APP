# Git и доставка в Apps Script

## Ветки

| Ветка | Назначение |
|-------|-----------|
| `main` | единственная ветка; всё, что выложено владельцу |

## Как файлы попадают в Google

GitHub и Apps Script **не связаны**. Файлы из `apps-script/` владелец
вставляет в редактор (или настроен `clasp push`, если подключён).
Репозиторий — история и источник правды для кода.

## Коммиты

- Одна законченная мысль, заголовок до ~72 символов, детали в теле.
- Код и его документы (`nav.md`, `SPEC_APP.md`, каталог) — в одном коммите.
- `reset --hard`, `--amend`, `push --force` — только с явного разрешения.
- Репозиторий **публичный**: в `APP_ALLOWED` заглушки, настоящие почты не
  коммитить (L-014). Если станет приватным — договориться отдельно.
